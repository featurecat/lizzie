Lizzie patched-0.7.4

(English / 日本語)

(Unofficial Windows package) This is an ALL-IN-ONE package of Lizzie, one of the most popular tools for Go AI. You need no installation, no Java setup, no GPU to enjoy it.

Contents

  • Lizzie: patched-0.7.4 on 2025-04-05 (Major bugs in Lizzie 0.7.4 are fixed.)
  • KataGo: 1.15.1 + 18 block network (kata1-b18c384nbt-s9996) + human SL model (b18c384nbt-humanv0)
  • Java: minimum runtime environment for Lizzie (from OpenJDK 11)

Usage

Right-click the downloaded file to UNZIP it (Never double-click the zip file directly to open it). Then just double-click "Lizzie" (Lizzie.vbs) in it. Press SPACE key to stop/start analysis. You may want to switch the rule from "Analyze" menu. You can also switch among four AIs from "Engine" menu:
  • KataGo (CPU): Slow but simple to use
  • KataGo (GPU): Faster if your GPU works properly. Note that the initial tuning takes a long time on the first run.
  • Human-like (CPU): Play against human-like AI. You can set the humanSL profile, e.g., "rank_5k" (5 kyu) or "proyear_1960" (professional style in 1960), from the Game menu. This doesn't affect the analysis; it only impacts the gameplay.
  • Human-like (GPU): Same as above.

Original feature

Stone entropy

If this feature is activated via the menu (View > KataGo settings > Estimate info > Show stone entropy), red dots will be plotted on the winrate chart. Their height indicates the uncertainty of the stones' life/death status. They tend to be higher in heated situations involving large capturing races or miai. Should they not be displayed, open the menu (View > KataGo settings > Estimate info > Display) and enable it.

This feature was imported from LizGoban. (I am giving up on integrating this feature into the original Lizzie, as it depends on other proposed changes that have not yet been accepted.)
